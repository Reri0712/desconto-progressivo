# Sistema de Desconto Progressivo - Loja Online

Este projeto é um programa em Python desenvolvido para calcular o desconto progressivo aplicado a compras em uma loja online com base no valor total[cite: 2].

## Regras de Desconto[cite: 2]
- Compras menores que R$ 200,00: 5% de desconto.
- Compras entre R$ 200,00 e R$ 299,99: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.
